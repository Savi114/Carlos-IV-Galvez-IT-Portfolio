Java console application

Zodiary

A Java application that loads astronomical observations from CSV files and compares a planet’s position across two dates. Users choose Jupiter, Mars, Saturn, or Venus and a location: Berlin or Buenos Aires. Results include the zodiac sector, season, and direction of movement.

  • Java
  • Object-oriented programming
  • CSV file handling
  • Input validation
  • IntelliJ IDEA
Explore features and screenshots

My contribution

Developed the Java classes, CSV loading, console interaction, observation comparison, and input validation. Used inheritance and method overriding to represent different planets through a shared parent class.

What I learned

Connecting Java classes into a working application, handling CSV data, validating console input, and testing boundary cases rather than only typical inputs.

Current scope

Zodiary works with the observations available in its supplied CSV files. It compares recorded positions; it does not retrieve live astronomical data.
